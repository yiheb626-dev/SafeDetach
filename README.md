# SafeDetach

轻量的 Windows 外接设备占用检查与弹出工具。使用 C# / WinForms，无需安装额外运行时（依赖系统 .NET Framework 4.5+）。

## 1. 功能

- **识别设备**：USB 移动硬盘、U 盘及其多个盘符，以及通过 Windows WPD 访问的 USB 手机、便携设备；已实测 Lexar ES3 和 Apple iPhone。
- **查看占用**：显示进程名、PID、文件路径或设备连接；同一进程合并显示，支持结束进程。
- **便捷操作**：侧栏选择设备、底部刷新、自动扫描。有占用时显示“强制弹出”，无占用时显示“安全弹出”。
- **强制弹出**：重新扫描并经确认后结束列出的占用进程，再请求 Windows 弹出；结束失败会停止操作，不强制卸载磁盘卷。

## 2. 实现方法与可能局限

- **设备与进程识别**：通过 WMI 和 Windows 设备接口枚举设备，扫描系统句柄及内存映射；对无路径的 WPD 连接，只读查询制造商、型号和序列号，匹配具体手机。
- **保护措施**：结束前校验 PID 与进程创建时间，拦截 Windows 关键进程；查询放在独立进程中并设置超时，安全弹出交由 Windows 系统接口处理。
- **权限与兼容性**：受保护进程、私有厂商协议等可能无法识别，必要时使用管理员模式。手机需解锁并允许电脑访问；其他厂商手机、真实多手机同时连接尚未实测。系统内部句柄接口也可能受 Windows 更新影响。
- **结果边界**：扫描是当前快照；已缓存内容且关闭连接的查看器不会列入。未检出占用不保证可拔出，以系统弹出成功提示为准。结束进程可能丢失未保存内容。
