# SafeDetach

轻量的 Windows 外接设备占用检查与弹出工具。使用 C# / WinForms，无需安装额外运行时（依赖系统 .NET Framework 4.5+）。

## 1. 功能

- **识别设备**：USB 移动硬盘、U 盘及其多个盘符，以及通过 Windows WPD 访问的 USB 移动设备；已实测 Lexar ES3、Apple iPhone 和 iPad，同时连接也能区分。
- **查看占用**：显示进程名、PID、文件路径或设备连接；同一进程合并显示，支持结束进程。
- **便捷操作**：当前设备每 15 秒自动扫描，上一轮未结束则跳过本次触发；切换设备保留各自结果，新结果整批更新，失败时保留上次完整结果。扫描时在占用进程数右侧显示转圈，底部仅显示错误。支持高 DPI 缩放与 Npcap 安装引导。有占用时显示“强制弹出”，无占用时显示“安全弹出”。
- **强制弹出**：扫描期间也可点击，等待当前设备完整扫描后确认；扫描失败或设备变化会取消。确认后结束列出的占用进程，再请求 Windows 弹出；结束失败会停止操作，不强制卸载磁盘卷。

## 2. 实现方法与可能局限

- **设备与进程识别**：通过 WMI、设备接口、系统句柄和内存映射识别占用；独立阶段并行执行，同一对象和映射避免重复查询，WPD 先按设备类型筛选再只读查询身份。Apple 服务连接解析本机 USBMux 握手，核对成功响应、USB 设备身份及两端进程，连接关闭后移除记录。
- **Apple 连接识别**：需另行安装 [Npcap](https://npcap.com/#download)。缺失提示中的“前往官网下载”会打开官方页面，由用户下载安装，再点击“安装后重试”。先启用 SafeDetach 监听，再连接设备或打开爱思等应用；旧连接需在传输结束后重连。只识别连接，不判断传输进度，握手不落盘。Npcap 不随包分发，未安装时仍可使用磁盘和 WPD 扫描。
- **保护措施**：结束前校验 PID 与进程创建时间，拦截 Windows 关键进程；句柄查询在独立进程中设置超时，连接监听在后台运行。设备变化、服务重启或监听丢包时清除旧归属，安全弹出交由 Windows 处理。
- **兼容性与边界**：移动设备需解锁并允许电脑访问，必要时使用管理员模式。Apple 补充识别限本机 IPv4 USBMux；受保护进程、其他私有协议、丢失握手等可能无法识别，其他厂商移动设备尚未实测。Windows 或 Apple 协议更新也可能影响结果。
- **结果边界**：扫描是当前快照；已缓存内容且关闭连接的查看器不会列入。未检出占用不保证可拔出，以系统弹出成功提示为准。结束进程可能丢失未保存内容。
